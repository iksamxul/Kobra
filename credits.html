The application

Kobra’s logo, interface and screenshots are from the Kobra desktop application. Screenshots use a disposable review profile with demonstration content. The illustrated feature-bar panels and the Editor window are drawn for this page from plain shapes and sample-film stills, and are labeled as illustrations until real screenshots replace them. The website’s aluminium display and the 3D Kobra emblem are original procedural Three.js models, not third-party hardware or downloaded models.

The website

Built with TypeScript, Vite and Three.js. Interface icons are inline geometric SVGs. Typography uses locally available system fonts. There are no analytics, remote fonts or third-party embeds.

Source and release information

Find the website source and development handoff at github.com/iksamxul/Kobra. Application downloads are published as GitHub Releases, with SHA-256 hashes in the release notes.
