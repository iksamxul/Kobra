# Screens the site needs

Every app image on the page comes from this folder as a 1440 px and a 2880 px WebP (crops: 1x and 2x of their CSS size). They are generated by `python scripts/screens.py` from full-size captures; boxes and sizes live in `scripts/screens.json`.

**Today all of them are interim**: made from the 1920×1200 captures in the desktop project's `review/modes/`, so every 2880 / 2x file is an enlargement (the script prints `upscaled` next to each). They are sharp at 1x and soft on 2x displays.

## How to replace them

1. Capture the app at **2880×1800** (a 1440×900 window at 200% scaling), one PNG per name below, in both appearances. Name them exactly `<name>.png`, for example `watch-dark.png`.
2. Put them in `showcase/captures/` (ignored by git), then run `npm run screens` (or `python scripts/screens.py --only watch`).
3. Crops are cut from the same captures with boxes in a 1920×1200 reference frame, so they scale automatically. If the new header (the feature bar) moves things, adjust the boxes in `scripts/screens.json`, rerun, and check with `node tests/capture.mjs`.

General state for every capture: demo library (Sintel, Big Buck Bunny, Flower), no toasts, no hover states, the "Your workspaces are now in Kobra Studio" hint dismissed, the window chrome exactly as in the app. Pearl and Midnight captures of the same screen must have an identical layout.

## Not built yet: the feature bar

These screens do not exist until the feature bar ships. Until then each panel shows an illustration (`src/content-html.ts`). When the captures are in place, run `npm run screens` and set `capture: true` for that tab in `src/content.ts`; the panel then uses `featurebar-<id>-{light,dark}-{1440,2880}.webp`.

| Name (`-light`, `-dark`) | App state |
|---|---|
| `featurebar-watch` | Kobra with the feature bar, Watch tab selected, Sintel paused at 0:20. |
| `featurebar-clips` | Clips tab: a clip from Big Buck Bunny being trimmed, 9:16 crop selected, speed 1.5×, a short caption. |
| `featurebar-convert` | Convert tab: a video chosen, "Shrink for sharing" with MP4 selected, the size estimate visible. |
| `featurebar-scenes` | Scenes tab: Sintel's detected scenes as thumbnails, one selected, Save frame and Make moments visible. |
| `featurebar-listen` | Listen tab: audio mode playing, visualizer moving, the equalizer open. |
| `featurebar-insights` | Insights tab: watch time by day for the demo library, the "kept on this device" note visible. |

Optional, for later: `editor` (the new Editor with source and program monitors and the multi-track timeline) could replace the illustrated window in the Editor section or the Studio stack's front card.
